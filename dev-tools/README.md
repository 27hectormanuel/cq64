# dev-tools

Costume Quest's Lua developer console for PC: in Costume Quest Mobile for Windows, the official
Windows release and the official Linux release.

- [HOWTO.md](HOWTO.md): install and use it (keys, files, building).
- [RESEARCH.md](RESEARCH.md): what the retail builds kept of the console, addresses, design and
  test results (2026-10-15).
- `windows/`: `dinput8.dll` for `Cq.exe`. `linux/`: the `LD_PRELOAD` library for `Cq.bin.x86`.
  `testing/`: the test helper scripts.

Built files: the GitHub release **Dev Console testing**.
